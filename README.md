# Ship Management API

A RESTful ship-management backend built with Node.js, Express, MongoDB/Mongoose, and JWT authentication.

## Features

- User registration and login
- JWT-protected routes
- Ship CRUD operations
- Validation and error handling
- Postman collection support

## Stack

- Node.js + Express.js
- MongoDB + Mongoose
- JWT + bcrypt.js
- dotenv

## Run

```bash
npm install
npm start
```

Create a `.env` file with the required MongoDB URI, JWT secret, and port before starting the API.

> Existing source files and API behavior are preserved; this README is only the organized entry point.
